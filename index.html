Interactive Workflow

3 Steps to Hundreds of Delivered Certificates

From a single image background to hundreds of tailored recipient certificates dispatched directly to individual inboxes.

STEP 01

Upload Template Canvas

Drag and drop any PNG, JPG, or WebP certificate template. The editor automatically preserves natural image aspect ratios and resolution with high-DPI scaling.

STEP 02

Import Data & Drag Fields

Import `.xlsx`, `.xls`, or `.csv` files. Every spreadsheet column dynamically becomes a draggable tag (e.g. {{name}}, {{course}}) you can position anywhere on canvas.

STEP 03

Export ZIP or SMTP Send

Instantly generate and download the entire batch as a single ZIP archive, or dispatch personalized HTML emails with high-res PNG certificates attached via your own verified SMTP server.

Enterprise Capabilities

Engineered For Performance & Precision

Every tool you need to design, customize, and bulk deliver high-resolution certificates with zero external design software.

Sub-Pixel Drag & Drop

Fluid canvas dragging with bounding-box hit testing, multi-level zoom (25% to 100%), and automatic boundary clamping for perfect placement.

20+ Curated Fonts

Calligraphy handwriting scripts, elegant traditional serifs, and modern clean sans-serifs with drop shadows, opacity control, and true multi-word Title Case formatting.

Per-Recipient Custom Overrides

Have an unusually long recipient name? Click their row in the live preview table to fine-tune font size or coordinates for that specific certificate without changing global settings.

Rich Email Composer

Built-in WYSIWYG editor with live column placeholder chips ({{firstName}}, {{name}}), hyperlink insertion, formatting shortcuts, and local template saving.

Client-Side Parallel ZIP

Generates certificates in memory with parallel canvas rendering and compresses them into a standard ZIP archive directly in your browser. Fast, private, and zero server strain.

Hardened SMTP Relay

Strict anti-SSRF protections block internal intranet probing. Enforces TLS certificate verification, anti-CRLF header sanitization, and full local credentials isolation.

Security First

Hardened Defense Architecture

We audited and hardened the application code with hacker-grade defensive controls to ensure zero unauthorized relay, no credential leakage, and strict memory safety.

SSRF & Port Guard
Blocks loopback (127.0.0.1), private LAN subnets (10.x, 192.168.x, 172.16.x), and AWS/cloud metadata (169.254.169.254).
Strict TLS Verification
Enforces cryptographic certificate verification on all outbound SMTP transmissions to prevent Man-in-the-Middle credential interception.
Anti-CRLF Injection
Sanitizes carriage returns and newlines from subject lines, recipient names, filenames, and email headers to eliminate SMTP protocol manipulation.
Zero Telemetry & Isolation
All spreadsheet parsing, image drawing, and ZIP creation run completely in your local browser sandbox. Nothing is uploaded to external clouds.
